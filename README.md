# Аудит рекламного кабинета Ilm Markazi

Разбор Facebook/Instagram Ads за **22.05 — 21.08.2026** (92 дня).

**Отчёт:** https://damir1703.github.io/ilm-markazi-audit/

## Что внутри

- сводка периода: 27 487 лидов, 900 продаж, $25 805 расхода, ROAS 6,24×
- разбор 27 082 потерянных сделок по причинам — 60% бюджета уходит в непродаваемые лиды
- почему просел август: доля тестового бюджета выросла с 8% до 33%
- разброс конверсии по менеджерам (1,22% — 3,83%) при одинаковых лидах
- плейсменты, формы, nurture-база
- $94 600 потенциала за квартал и план работ по четырём этапам с чек-листом

## Источники данных

- Facebook Graph API v21 — insights по дням, адсетам, объявлениям, плейсментам, гео и демографии
- amoCRM API v4 — 36 788 сделок, статусы, причины потерь, ответственные
